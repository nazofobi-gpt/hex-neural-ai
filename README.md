# Hex Neural AI

A recursive, brain-inspired visual environment for building AI applications from hexagonal computational cells.

## Status

Early architecture and protocol design.

## Core ideas

- Hexagonal cells connect through six typed faces.
- Cells can contain adaptive neural microcircuits.
- Groups of cells can collapse into higher-level cells with the same external interface.
- Semantic payloads and neural control signals are separate planes.
- User feedback may adapt routing and control behavior within bounded, reversible learning rules.
- Security, permissions, billing limits, and data-access policy remain outside learned neural state.

## Development order

1. Hex Neural Application Protocol v0.1
2. Infinite hex canvas
3. Typed face-to-face data transfer
4. Recursive cluster composition
5. Deterministic workflow runtime
6. Neural controller
7. User-feedback plasticity
8. Privacy, security, versioning, benchmarking, and private-alpha hardening
